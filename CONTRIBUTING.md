# Contribuir a Osteo3D

1. Instala Node.js 20+ y pnpm 11.
2. Ejecuta `pnpm install`.
3. Ejecuta `pnpm test` y `pnpm build` antes de abrir un pull request.
4. Mantén los cambios pequeños, documentados y compatibles con el uso offline.

Las pruebas de humo se ejecutan también en GitHub Actions junto con el build de GitHub Pages.
